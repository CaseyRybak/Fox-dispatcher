# Writing Repository Skills

Transform repeated project knowledge into a focused capability that future agents can discover at the right moment.

## Identify reusable knowledge

Choose a workflow with stable triggers, concrete inputs, observable outputs, and evidence from real repository work. Gather the smallest set of facts another capable agent would otherwise need to rediscover.

Place information according to its role:

- skills: reusable procedures and tool workflows;
- specifications: durable product and domain truth;
- execution plans: intended work and current decisions;
- `AGENTS.md`: domain maps and links to deeper artifacts.

## Design the skill

1. Give the skill a short action-oriented name.
2. Put trigger conditions and supported tasks in the frontmatter description.
3. Keep `SKILL.md` focused on the core procedure.
4. Move detailed schemas, examples, and variants into directly linked references.
5. Add scripts when deterministic repetition creates clear value.
6. Express guidance as positive actions with visible outcomes.
7. Complete every section with usable content grounded in the repository.

Use `skill-creator` to initialize metadata, then validate the result with `quick_validate.py`. Exercise scripts with representative inputs. Exercise complex workflows through a fresh agent brief and inspect the resulting artifacts.

## Evolve the skill

Observe real usage, friction, and repeated discoveries. Update the procedure when evidence shows a stable improvement. Keep provenance and relevant upstream versions visible for adapted third-party material.
