# Browser storage and bundle behavior

## Browser storage

Persist a small versioned document containing user-editable observations and parameters. Validate stored data through the same application boundary as imported JSON. Provide migration or reset behavior for older versions.

Keep derived reports, private data, tokens, internal flags, and transient UI state outside the persisted document. Handle unavailable storage and quota errors as visible recoverable states.

## Bundle behavior

Import modules through analyzable paths. Load interaction-critical code with the initial view and defer substantial optional surfaces when measurement supports the split. Give third-party scripts an explicit purpose and load phase.

Use repository-pinned tools for bundle analysis, SVG optimization, and dependency inspection. Preserve results as review evidence linked from the active execution plan.

## Evidence

Inspect the production bundle, browser console, network activity, and storage schema. Pair performance changes with before-and-after measurements on the same scenario.
