# Specification review brief

Use this brief for an independent review of a substantial specification before execution planning.

## Reviewer context

Provide:

- specification path;
- intended user outcome;
- linked domain maps and decisions;
- acceptance evidence expected from the finished work.

## Review lenses

Evaluate:

1. Coverage of the stated intent and user outcomes.
2. Consistency between domain concepts, examples, interfaces, and interaction behavior.
3. Clarity of terms that influence implementation choices.
4. Scope fit for one execution plan or a clear decomposition into several outcomes.
5. Concrete acceptance evidence for each meaningful behavior.
6. Alignment with current DDD and hexagonal boundaries.
7. Traceability from decisions to repository artifacts.

## Response shape

Return:

- readiness: ready for planning or revisions useful;
- findings with section references and implementation impact;
- questions that resolve material ambiguity;
- concise improvement suggestions;
- a final mapping from acceptance evidence to specification sections.
